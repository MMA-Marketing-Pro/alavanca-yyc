# Logo

Place the Alavanca logo here.

- **Filename:** `logo.png` or `logo.svg`
- **Recommended:** SVG or PNG with transparent background, minimum 400px wide.
- **Note:** The navbar is dark, so a white (light-colored) logo reads best. A dark version (for the booking page / light surfaces if needed) can live alongside it as `logo-dark.png`.

The current site uses a landscape white wordmark — upload the highest-resolution original you have.
