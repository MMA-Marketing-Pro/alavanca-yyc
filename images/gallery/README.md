# Gallery Photos

Real facility + action photos from each of Alavanca's three locations.

- **Filename format:** `{location}-{description}-{##}.jpg`
  - Examples: `hq-mat-space-01.jpg`, `shawnessy-class-02.jpg`, `airdrie-exterior-01.jpg`
- **Recommended:** Landscape orientation, minimum 1600×1200px.

Stock action photos from picsum.photos are used as placeholders in the HTML until real photos are dropped in. When real photos are provided, update the `<img src>` attributes across the generated HTML to point at `images/gallery/{filename}.jpg`.
