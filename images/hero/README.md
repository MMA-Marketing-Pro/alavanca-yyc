# Hero Images

Full-bleed hero banners — one per page where possible.

- **Filename format:** `hero-{page-slug}.jpg`
  - Examples: `hero-home.jpg`, `hero-bjj.jpg`, `hero-muay-thai.jpg`, `hero-mma.jpg`
- **Recommended:** Landscape 16:9, minimum 2560×1440px. Dark mid-tones so the overlay text stays legible.

Best subjects: BJJ rolling action, Muay Thai pad work, MMA sparring, gym wide shots at each of the three locations.
